# Kraken Community Iceplex — Google Calendar

Subscribe to the [Kraken Community Iceplex](https://www.krakencommunityiceplex.com/) public drop-in calendar in Google Calendar, Apple Calendar, Outlook, or any app that supports iCalendar (`.ics`) subscriptions.

The calendar updates automatically every day via GitHub Actions, pulling directly from the iceplex's public schedule.

---

## Subscribe (live, auto-updating)

Copy one of these URLs and add it as a calendar subscription:

| Calendar | Subscribe URL |
|---|---|
| Hockey drop-in (all levels) | `https://raw.githubusercontent.com/mwollum/kraken-iceplex-calendar/main/kraken_hockey.ics` |
| Stick & Puck | `https://raw.githubusercontent.com/mwollum/kraken-iceplex-calendar/main/kraken_stick_puck.ics` |
| Public Skate | `https://raw.githubusercontent.com/mwollum/kraken-iceplex-calendar/main/kraken_public_skate.ics` |
| Everything | `https://raw.githubusercontent.com/mwollum/kraken-iceplex-calendar/main/kraken_all.ics` |

### Google Calendar

1. Open [calendar.google.com](https://calendar.google.com)
2. In the left sidebar, click **+** next to "Other calendars" → **From URL**
3. Paste the subscribe URL above → **Add calendar**

> Google Calendar refreshes subscribed calendars roughly every 24 hours.

### Apple Calendar (iPhone / Mac)

1. Open the **Calendar** app
2. **File → New Calendar Subscription** (Mac) or **Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar** (iPhone)
3. Paste the URL → **Subscribe**

### Outlook

1. Open [outlook.com](https://outlook.com) → calendar view
2. **Add calendar → Subscribe from web**
3. Paste the URL
